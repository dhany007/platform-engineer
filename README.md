# Platform Engineering Learning Path

A learning repository for moving from Go backend engineering into platform engineering.

## Structure

- `roadmap/` — the 12-week, day-by-day course with learning context, hands-on tasks, and reading sources.
- `notes/` — concept notes and references.
- `labs/` — hands-on exercises, from Linux through observability.
- `projects/` — practical projects that combine multiple topics.

Start with the [12-week course](roadmap/12-week.md). It contains 60 study sessions, five per week. Keep each exercise in its topic folder, and document prerequisites, commands, expected results, and cleanup steps in the exercise README.
